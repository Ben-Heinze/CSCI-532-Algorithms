Linear Programming 

A structed way to optimize a goal by turning knobs and following certain rules 

 

example:  

goal (objective): get as rich as possible 

knobs (decision variables): job hunting, education, risk 

rules (constraints): no robbing, get enough sleep, see kids more than once a month 

 

Vertex cover: 

objective: select smallest subset of verticies 

decision vars: select vertex 1? do we select vertex 2? ... 

constraints: every edge needs a selected vertex 

 

To define linear programming 

Figure out what the knobs are 

Create objective (what to minimize/maximize) 

add constraints
