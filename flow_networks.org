s-t cut definition: suppose G is a flow network and nodes in G are divided into two sets, A and B, such that s \in A and t \in B. We call (A,B) in s-t cut. The capacity of the cut, c(A,B), is the sum of capacities of all edges out of A. Source s and sink t cannot be in the same set. We are guaranteed to see everything that travels from s to t. It is possible to count the same flow twice if if a flow goes through s-t, then back t-s, then back s-t, but that does we don't care about that.

How do we turn this into a flow network? 

 

Algorithm: 

Build a flow network 

Make a node for each employee, a node for each holiday, a source and a sink 

connect the source to each mployee node with a capacity of 3 

connect each holiday node to the sink with a capacity of 1 

if an employee is able to work a holiday, connect them with a capacity of 1 

Find the max flow 

If an employee has outgoing edge to carry flow, assign them to work that holiday 

 

Running time: O(time to build G) + O(Max flow) + O(time to translate solution) 

time to build and translate boil down to O(nm)
